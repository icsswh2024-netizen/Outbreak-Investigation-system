# การเชื่อมต่อฐานข้อมูลกลาง (Google Sheets + Apps Script)

ทำให้ระบบ **รองรับหลายเครื่อง/หลายมือถือบันทึกพร้อมกัน** เข้าที่เดียวกัน โดยเก็บข้อมูลใน Google Sheets
และให้ **แอดมินแก้แบบสอบถามในหน้าเว็บแล้วมีผลกับชีต** โดยตรง

ชีตจะมี 2 แท็บ (สร้างอัตโนมัติ):
- **ข้อมูลแบบสอบถาม** — คำตอบทุกฉบับ (1 แถว/1 การบันทึก) พร้อมคอลัมน์ `_JSON` เก็บข้อมูลเต็ม
- **การจัดการแบบสอบถาม** — โครงสร้างแบบสอบถาม (schema) ที่แอดมินแก้ผ่านหน้าเว็บ

---

## ขั้นตอนติดตั้ง

### 1) สร้าง Google Sheet
- ไปที่ https://sheets.new ตั้งชื่อไฟล์ เช่น `Outbreak Investigation DB`
- ไม่ต้องสร้างแท็บเอง สคริปต์จะสร้าง "ข้อมูลแบบสอบถาม" และ "การจัดการแบบสอบถาม" ให้อัตโนมัติ

### 2) ใส่โค้ด Apps Script
- ในชีต เมนู **ส่วนขยาย (Extensions) → Apps Script**
- ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาจากไฟล์ **`Code.gs`** ลงไป
- กดบันทึก (💾)

### 3) Deploy เป็น Web App
- กด **Deploy → New deployment**
- ไอคอนเฟือง ⚙️ เลือกชนิด **Web app**
- ตั้งค่า:
  - **Execute as:** `Me` (ตัวคุณเอง)
  - **Who has access:** `Anyone` (เพื่อให้เว็บเรียกได้โดยไม่ต้องล็อกอิน)
- กด **Deploy** → อนุญาตสิทธิ์ (Authorize) ให้สคริปต์เข้าถึงชีต
- คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`)

### 4) เชื่อมกับเว็บแอป
- เปิดไฟล์ `index.html` หาบรรทัด:
  ```js
  const API_URL = ''; // <<< วาง URL Web App ที่นี่
  ```
- วาง URL ที่คัดลอกมา เช่น:
  ```js
  const API_URL = 'https://script.google.com/macros/s/AKfycbxxxxxxxx/exec';
  ```
- บันทึกและ push ขึ้น main (หรือแจ้งให้ช่วย commit ให้)

### 5) ตั้งค่าแบบสอบถามครั้งแรก
- เปิดเว็บ → **Admin → จัดการแบบสอบถาม → บันทึกแบบสอบถาม**
  เพื่อส่ง schema เริ่มต้นขึ้นแท็บ "การจัดการแบบสอบถาม"

เสร็จแล้ว! ทุกการบันทึกจะเข้าชีตทันที และเครื่องอื่นจะเห็นข้อมูลเมื่อเปิด/รีเฟรชหน้า Admin (รีเฟรชอัตโนมัติทุก 20 วินาที)

---

## การทำงาน (สรุป)
- **บันทึกคำตอบ:** เว็บ `POST {action:'submit'}` → ต่อแถวใน "ข้อมูลแบบสอบถาม" (มี `LockService` กันเขียนชนกัน)
- **แอดมินแก้แบบสอบถาม:** เว็บ `POST {action:'saveSchema'}` → เขียนทับ schema ในแท็บ "การจัดการแบบสอบถาม"
- **โหลดข้อมูล:** เว็บ `GET ?action=load` → คืน `schema` + `records` ให้ทุกเครื่องเห็นตรงกัน

## อัปเดตโค้ดภายหลัง
ถ้าแก้ `Code.gs` ต้อง **Deploy → Manage deployments → (ดินสอ) → Version: New version → Deploy** เพื่อให้ URL เดิมใช้โค้ดใหม่

## หมายเหตุความปลอดภัย
`Who has access: Anyone` = ใครมี URL ก็ส่งข้อมูลได้ เหมาะกับการใช้ภายใน/ช่วงเก็บข้อมูล
ถ้าต้องการจำกัดสิทธิ์ ควรเพิ่มรหัสลับ (token) ตรวจใน `doPost`/`doGet` หรือใช้ Google Identity — แจ้งได้ถ้าต้องการให้เพิ่ม
